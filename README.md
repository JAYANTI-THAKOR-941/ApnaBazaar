# ApnaBazaar — Django Store

Django store prototype with product pages, registration and OTP verification templates.

## Project structure

`ApnaBazaar/`, `main/models.py`, `main/views.py`, `main/templates/main/`, `manage.py`

## Getting started

```bash
git clone https://github.com/JAYANTI-THAKOR-941/ApnaBazaar.git
cd ApnaBazaar
```

Create a virtual environment, install Django and any required imports, configure local settings, then run `python manage.py migrate` and `python manage.py runserver`.
